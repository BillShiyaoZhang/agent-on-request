Agent on Request - visual symposium materials

Current presentation: 3 diagram pages, A4 landscape.
- Project interpretation: pages 1-2.
- Interaction guide: page 3, a six-frame walkthrough.

Main PDFs are in pdf/ in the ZIP and ../pdf/ in the repository.
boards/ contains the same three pages as 150-dpi PNGs.
materials-preview.png is the overview image.

The pages use vector diagrams and short labels. Controls are schematic;
follow the labelled controls in the actual demo. Guided's private-material
request is Alice's. Summary reaches Bob only if approved. The venue booking
requires its own decision. A new visitor does not inherit the prior records.

submission-and-facilitation-draft.txt is separate preparation/reference text,
not part of the visual presentation. It retains the English submission copy,
Chinese facilitator script and operational notes from the initial draft.

assets/ retains the original real Guided captures and their verification.
The final visual boards do not embed these text-heavy screenshots.
build_materials.py is the editable vector-PDF source (uv + reportlab/pypdf).
capture-demo.mjs captures a disposable local Guided run (nvm + Node 26+).
